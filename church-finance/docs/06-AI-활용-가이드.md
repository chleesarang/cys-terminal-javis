# 🤖 무료 AI 활용 가이드 — 비용 0원으로 쓰기

> **핵심**: 보아스는 계산·결산·보고서를 **AI 없이** 앱이 직접 합니다. AI는 **사진(영수증·헌금 명단)이나 정리되지 않은 글**을 앱이 읽을 수 있는 짧은 줄로 바꿀 때만 씁니다. 앱이 AI에 직접 접속하지 않으므로 **API 키나 과금이 없습니다.**

## 1. 입력 방법별로 가장 싼 길

| 무엇을 입력하나 | 가장 좋은 방법 | AI 비용 |
|---|---|---|
| 헌금 명단(글) | 헌금 화면에 직접 타이핑 또는 붙여넣기 | 0 |
| 말로 부르기 | 휴대폰 키보드의 🎤 → 헌금 화면 | 0 |
| 녹음해 둔 파일 | 갤럭시 '음성 녹음 → **텍스트 변환**', 아이폰 '음성 메모 → **전사**' → 복사해 붙여넣기 | 0 |
| 지출 1~2건 | 지출 화면에 금액과 메모만 입력(항목 자동 분류) + 📷 | 0 |
| 영수증 여러 장 | 무료 AI에 사진 → 답변 붙여넣기 | 무료 플랜 범위 |
| 헌금 봉투·계수표 사진 | 무료 AI에 사진 → 답변 붙여넣기 | 무료 플랜 범위 |
| 외부에서 받은 녹음(m4a 등) | **Gemini 무료**(오디오 파일 업로드 가능) | 무료 플랜 범위 |

## 2. 어떤 AI를 쓸까 (2026년 11월 조사 기준)

| | Gemini (무료) | Claude (무료) | ChatGPT (무료) |
|---|---|---|---|
| 영수증 사진 | ○ | ○ | ○ (사진 업로드 하루 몇 건으로 제한) |
| 녹음 파일 | **○** | ✕ | ✕ (유료만) |
| 지침 저장 | **Gem**(웹에서 만들기) | **프로젝트**(최대 5개) | **프로젝트** |
| 추천 | 🥇 녹음까지 되므로 1순위 | 🥈 사진 정리 정확도 좋음 | 사진이 적을 때 |

> 무료 플랜의 한도는 각 회사 사정에 따라 수시로 바뀝니다. **월 $20 안팎의 유료 플랜**은 매주 사진을 수십 장 처리하는 큰 교회에만 필요합니다. 보아스는 API를 쓰지 않으므로 **구독만으로 충분**합니다(API 키 불필요).

## 3. 처음 한 번: 지침 저장 (5분)

1. 보아스 **더보기 › 🤖 AI 도우미 › 📋 지침 복사**를 누릅니다. 지침에는 교회 이름, 출력 형식, **예산 항목 코드표**가 들어 있습니다.
2. AI 앱에서 지침을 저장합니다.
   - **Gemini**: 웹(gemini.google.com) › Gem 만들기 › 이름 "보아스 재정" › 지침 칸에 붙여넣기 › 저장
   - **Claude**: claude.ai › 프로젝트 › 새 프로젝트 "보아스 재정" › 프로젝트 지침에 붙여넣기
   - **ChatGPT**: chatgpt.com › 프로젝트 › 새 프로젝트 › 지침에 붙여넣기
3. 예산 항목을 바꾸면 지침을 **다시 복사해 갱신**하세요.

## 4. 매번: 사진 보내고 붙여넣기 (1분)

1. 저장해 둔 Gem·프로젝트를 엽니다.
2. 영수증 사진을 올리고 **`영수증`** 한 단어만 보냅니다. 헌금 명단이면 **`헌금`**, 정리 안 된 글이면 **`정리`**라고 씁니다.
3. AI 답변(아래 같은 줄들)을 **그대로 복사**합니다.
   ```
   O|20261107|262|23000|이마트 다과
   O|20261107|251|152300|전기요금
   T|175300
   ```
4. 보아스 **AI 도우미 › ③ 붙여넣기 › 확인 ▶** 를 누릅니다.
   - 마지막 줄 `T|합계`와 각 줄의 합을 **앱이 다시 검산**합니다. 다르면 빨갛게 경고합니다.
   - 항목 코드가 `?`이거나 틀리면 앱이 메모를 보고 **스스로 분류**합니다.
5. 표에서 확인·수정하고, 필요하면 **📷 영수증 사진 첨부** 후 **✔ 모두 저장**을 누릅니다.

## 5. 답변 형식 (토큰을 아끼는 방법)

```
헌금  I|날짜|코드|이름 또는 #번호|금액     예) I|20261108|102|#12|100000   (미국: I|20261108|102|#12|150.00)
지출  O|날짜|코드|금액|내용              예) O|20261107|262|23000|다과    (미국: O|20261107|262|23.50|Costco)
합계  T|합계                             예) T|123000                     (미국: T|173.50)
```

- 이 형식은 같은 내용을 JSON으로 받을 때보다 **토큰이 1.6~2.6배 적게** 듭니다. 무료 한도를 더 오래 쓸 수 있습니다.
- 지침을 한 번 저장해 두면 매번 보내는 말은 **한 단어**뿐입니다.

## 6. 개인정보 원칙
- 장부와 명부 파일 자체는 **절대 AI에 올리지 않습니다**. 보아스는 인터넷으로 아무것도 보내지 않습니다.
- 헌금 명단 사진을 보낼 때는 이름보다 **교인번호**가 보이게 하고, 필요한 부분만 찍습니다.
- 영수증처럼 교인 이름이 없는 자료를 우선 AI로 처리합니다.
- AI 서비스 설정에서 "대화 내용을 학습에 사용"하는 옵션이 있으면 **끄는 것**을 권장합니다.

## 7. 잘 안 될 때
| 증상 | 해결 |
|---|---|
| AI가 설명을 길게 붙임 | 지침이 저장된 Gem·프로젝트에서 보냈는지 확인합니다. "줄만 출력"이라고 한 번 더 말합니다. |
| 합계 불일치 경고 | 사진과 대조해 금액을 고칩니다. 영수증 할인·포인트 금액을 AI가 빠뜨리는 일이 많습니다. |
| 코드가 엉뚱함 | 표에서 항목을 바꾸면 됩니다. 앱이 그 메모를 학습해 다음부터 맞춥니다. |
| 날짜가 ? | 붙여넣기 칸 아래 **날짜가 ?일 때** 값이 쓰입니다. |
