# 🏢 회사용 — 보아스 배포 · 보급 · 교육 · 지원 가이드

> 대상: 보아스를 무료로 배포하고 업데이트·지원하는 **회사(배포사) 실무자와 교육 강사**.
> 목표: 교회가 **첫 주일 안에 혼자 쓸 수 있게** 만들고, 회사는 교회 자료에 **전혀 접근하지 않는** 구조를 지키는 것입니다.

---

## 1. 핵심 메시지 (교회에 설명할 때 3문장)

1. **무료이고 서버가 없습니다.** 자료는 교회 기기 안에만 암호화되어 있어 회사도 볼 수 없습니다.
2. **주일 5분, 지출 30초.** 번호·말·사진으로 입력하면 결산과 제직회 보고서가 자동으로 나옵니다.
3. **감사에 강합니다.** 고친 흔적까지 남고, 영수증 원본과 보고서가 ZIP 하나로 묶여 나옵니다.

---

## 2. 배포 (최초 1회, 약 30분)

보아스는 정적 파일(HTML·JS·CSS)뿐이라 **무료 정적 호스팅**으로 배포합니다. 반드시 **https**로 제공해야 합니다(브라우저 암호화 기능의 필수 조건).

### GitHub Pages로 배포하기
1. 회사 GitHub 조직에 공개 저장소를 만듭니다(예: `boaz-app`).
2. 이 프로젝트의 `church-finance/` 폴더 **내용 전체**를 저장소 루트에 올립니다(`tests/`는 빼도 됩니다).
3. 저장소 **Settings › Pages › Branch: main / root**를 선택하고 저장합니다.
4. 몇 분 뒤 `https://<조직>.github.io/boaz-app/` 주소가 생깁니다. 이 주소가 교회에 안내할 **앱 주소**입니다.
5. (선택) 회사 도메인 연결: `app.회사도메인` → Pages 설정 › Custom domain, **Enforce HTTPS** 켜기.

### 배포 전 회사 정보 넣기
`config.js`의 `SUPPORT` 항목에 회사명, 안내 문구, 후원 계좌·링크, 문의처를 넣습니다. 비워 두면 표시되지 않습니다.

### 보안 필수 설정 (반드시)
- 저장소 관리자 전원 **2단계 인증(2FA)**
- `main` 브랜치 **보호 규칙**: 직접 푸시 금지, 리뷰 1명 이상 승인 후 병합
- 배포 저장소에 쓰기 권한이 있는 사람을 최소화
- 이유: 교회 자료는 기기 안에 있지만 **앱 코드는 배포 주소에서 내려받습니다.** 배포 저장소가 뚫리면 악성 코드가 배포될 수 있으므로 코드 저장소 보안이 곧 교회 자료 보안입니다.
- 보안 요구가 높은 교회에는 "폴더를 내려받아 교회가 직접 호스팅"하는 방법도 안내할 수 있습니다.

## 3. 업데이트 · 릴리스 절차

1. 변경 → `npm test`(단위 테스트) → `node tests/e2e.cjs`(브라우저 종단 테스트) **모두 통과**
2. 화면이 바뀌었으면 `node tests/shots.cjs`로 매뉴얼 그림을 다시 만듭니다.
3. `config.js`의 `version`과 `sw.js`의 `VERSION`을 올립니다(예: `1.1` / `boaz-v1.1`).
4. 리뷰 후 `main`에 병합 → Pages가 자동으로 배포합니다.
5. 교회 앱은 다음에 열 때 새 버전을 받습니다(인터넷 연결 시).
6. **공지**를 보냅니다(아래 템플릿).

### 업데이트 공지 템플릿
```
[보아스 V1.1 업데이트 안내]
· 새 기능: (예) 은행 거래내역 엑셀 자동 대조
· 고친 점: (예) 미국 모드 수표 번호 표시
· 할 일: 앱을 한 번 닫았다 다시 여시면 적용됩니다. 업데이트 전에 백업을 권장합니다.
· 교회 자료는 그대로 유지됩니다(기기 안에 있음).
문의: (연락처)
```

## 4. 교회 온보딩 프로세스 (교회 1곳당 약 2시간, 4주)

| ② 사전 준비 안내 | D-7 | 회사 → 교회 | 아래 **준비물 체크리스트** 발송 | 준비 완료 회신 |
| ③ 설치·설정 세션 | D-day (40분) | 회사 + 회계 + 재정부장 | 원격 화면 공유로 설치 → 처음 설정 → 복구코드 2부 작성 → 명부 가져오기 → 예산·이월금 | 실사용 준비 |
| ④ 첫 주일 동행 | D+3~7 | 회사(원격) | 첫 헌금 입력·계수표·백업을 함께 진행 | 첫 주 입력 완료 |
| ⑤ 첫 월 결산 동행 | D+30 | 회사(원격) | 월간 보고서 → 마감 → 백업 | 첫 제직회 보고 |
| ⑥ 자립 확인 | D+45 | 회사 | 만족도·불편 사항 설문, FAQ 반영 | 자립 교회 등록 |

- [ ] 사용할 기기: 회계 휴대폰 + 교회 PC(크롬 또는 엣지 최신 버전)
- [ ] 교인 명부 엑셀(번호, 이름, 주정, 연락처) — **주민등록번호는 미리 모으지 마세요**
- [ ] 올해 예산서(관·항 목록과 금액)
- [ ] 앱 시작일 기준 **통장 잔액**(전기 이월금으로 입력)
- [ ] 교회 고유번호(미국: EIN), 주소, 대표자 이름
- [ ] 복구코드를 보관할 **봉투 2개**와 보관자 2명(담임목사, 재정부장)

### C. 1:1 원격 교육 (30분, 개별 교회)
온보딩 ③단계와 함께 진행합니다. 강사는 **진행만 안내**하고 입력은 반드시 교회 담당자가 직접 합니다.

### D. 짧은 영상 시리즈 (각 2~3분, 회사 유튜브·카톡 채널용)
| 편 | 제목 | 내용 |
|---|---|---|
| 1 | 5분 만에 시작하기 | 설치 → 처음 설정 → 복구코드 |
| 2 | 주일 헌금 5분 끝 | 번호·주정 자동·말로 입력·계수표 |
| 3 | 영수증은 찍기만 | 지출 메모 자동 분류·지출결의서 |
| 4 | 제직회 보고서 버튼 하나 | 주·월·분기·연 보고서·마감·백업 |
| 5 | 연말 영수증 | 한국 기부금영수증 / 미국 Contribution Statement |
| 6 | 무료 AI로 영수증 몰아 처리 | 지침 저장 → 사진 → 붙여넣기 |

촬영 팁: 예시 데이터만 쓰고, 실제 교회 이름·교인 이름이 화면에 나오지 않게 합니다. `node tests/shots.cjs`로 만든 그림을 썸네일로 활용할 수 있습니다.

### 강사 진행 원칙
- 교회 자료를 **회사가 대신 입력하지 않습니다.** 담당자가 직접 해 봐야 자립합니다.
- 설명보다 **실습 먼저**: "따라 해 보세요 → 결과 확인 → 이유 설명" 순서로 진행합니다.
- 어르신 담당자는 **글자 크게**(설정 › 글자 크기)와 **말로 입력**을 먼저 알려 드립니다.
- 교육이 끝날 때 반드시 **백업 1회**와 **복구코드 보관 확인**을 합니다.

### 교육 평가
[학습 가이드의 확인 문제 10개](03-재정담당자-학습가이드.md)로 7개 이상 맞으면 수료로 봅니다.

## 6. 교회 지원 (고객 지원) 원칙

### 절대 원칙 — 개인정보
- 회사 직원은 교회에 **비밀번호·복구코드를 절대 묻지 않습니다.**
- 교회의 **백업 파일이나 장부 파일을 받지 않습니다.** 문제 재현은 예시 데이터로 합니다.
- 원격 지원은 **교회가 직접 조작하는 화면 공유**로만 하고, 교인 명부 화면은 가리게 안내합니다.
- 문의 기록에 교인 이름·금액을 적지 않습니다.

### 문의 처리
| 단계 | 기준 |
|---|---|
| 접수 채널 | 카카오톡 채널 / 이메일 / 문의 양식 (회사 선택) |
| 1차 응답 | 영업일 1일 이내 |
| 자주 묻는 질문 | [FAQ](09-자주묻는질문.md)로 먼저 안내하고, 새 질문은 매월 FAQ에 추가 |
| 버그 | 재현 절차(예시 데이터) + 기기·브라우저 버전 → 개발 → 다음 릴리스 |

### 문의 접수 템플릿 (교회가 채워 보내는 양식)
```
교회명(선택):            지역: 한국 / 미국
기기: (예) 갤럭시 S23, 크롬 / 윈도우 PC, 엣지
앱 버전: (화면 왼쪽 위 V1.0)
무엇을 하려고 했나요:
어떤 화면·메시지가 나왔나요: (교인 이름·금액이 보이지 않게 캡처)
```

## 7. 후원 안내 원칙

- 보아스의 **모든 기능은 무료**이며, 후원 여부에 따라 기능을 제한하지 않습니다.
- 후원 안내는 앱 **설정 화면 맨 아래**에만 표시합니다(`config.js › SUPPORT`). 팝업·반복 요청은 하지 않습니다.
- ⚠ **세무 확인 필요**: 회사가 **영리법인**이면 교회가 보낸 '후원금'은 교회 입장에서 기부금(세액공제 대상)이 아니라 **서비스 대가나 지원금**으로 처리될 수 있습니다. 반대로 회사(또는 별도 법인)가 **비영리·공익 단체**라면 기부금영수증을 발급할 수 있는지 확인이 필요합니다. 후원을 받기 전에 **세무사와 처리 방식**(세금계산서, 기부금영수증 가능 여부, 미국 교회의 송금 처리)을 정하세요.
- 교회 장부에서는 후원을 **운영비 › 기관·단체 후원** 같은 지출 항목으로 기록하도록 안내합니다.
