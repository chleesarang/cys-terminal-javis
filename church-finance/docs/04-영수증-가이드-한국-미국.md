# 📄 기부금영수증 가이드 — 한국 교회 / 미국 이민교회

> 보아스는 처음 설정할 때 고른 **지역·영수증 방식**에 따라 영수증 서식이 자동으로 바뀝니다(**설정 › 교회 정보 › 지역 · 영수증 방식**). 첫 거래를 입력한 뒤에는 금액 단위(원/달러)가 달라지므로 바꿀 수 없습니다.

| 구분 | 🇰🇷 한국 교회 | 🇺🇸 미국 이민교회 |
|---|---|---|
| 통화 | 원(₩), 정수 | 달러($), 센트까지 |
| 영수증 이름 | 기부금영수증 | Contribution Statement (헌금 영수증, 한영 병기) |
| 근거 | 소득세법 시행규칙 [별지 제45호의2서식] | IRS Publication 1771, 526, 1828 |
| 기부자 식별번호 | 주민등록번호(영수증 희망자만, 암호화) | **넣지 않음**(SSN 불필요) |
| 교회 식별번호 | 고유번호(사업자등록번호) | EIN(선택) |
| 내역 표시 | 월별 합계 · 코드 41(종교단체) | **헌금별 날짜·항목·방법·금액** + 연 합계 |
| 필수 문구 | 법령 증명 문구 | "No goods or services were provided … other than intangible religious benefits." |
| 발송 시기 | 연말정산 전(1월) | 관행상 다음 해 1월 31일까지(법정 기한 아님) |
| 보관 | 발급명세 5년 | 교회 기록 보관(권장) |

## 🇰🇷 한국 교회 — 기부금영수증

### 앱에서 하는 일
1. **설정**에 교회 이름, **고유번호**, **소재지**, **대표자**를 입력합니다.
2. **교인** 화면에서 영수증을 원하는 분의 **주민등록번호**와 **주소**를 입력합니다. 암호화되어 저장되고 화면에서는 가려 보입니다.
3. **영수증** 화면에서 귀속 연도를 고르고 **발급·인쇄** 또는 **전체 발급·인쇄**를 누릅니다.
4. **발급명세 대장(엑셀)** 을 저장해 **5년간 보관**합니다.

### 앱이 자동으로 해 주는 것
- 연도별 일련번호(`2026-001`)를 중복 없이 매기고, 재발급하면 이전 번호를 '무효'로 대장에 남깁니다.
- **헌금 항목만** 합산합니다. 이자수입, 잡수입, 차입금처럼 '기부금영수증 대상'이 꺼진 항목은 빠집니다.
- 기부 내용에 **코드 41(종교단체 기부금)**, 구분 '금전', 월별 금액을 표시합니다.
- 연간 발급 합계가 **3억 원 이상**이면 전자기부금영수증 의무 안내를 띄웁니다.

### 꼭 알아 둘 규정 (조사 확인 결과)
| 항목 | 내용 | 확인 수준 |
|---|---|---|
| 서식 | 소득세법 시행규칙 [별지 제45호의2서식]. 2026.1.2 개정 표기가 확인됨 | 개정 사실은 확인. **개정 내용은 원문과 대조 필요** |
| 기부금 코드 | **41** = 종교단체 기부금, **40** = 종교단체 외 일반기부금 | 법령 서식 코드표 확인 |
| 발급명세 보관 | 기부자별 발급명세 작성, 발급일부터 **5년** 보관(소득세법 제160조의3) | 2차 자료끼리 일치, 법령 원문 대조 권장 |
| 발급합계표 | 다음 연도 **6월 30일**까지 관할 세무서 제출(서식: 별지 제29호의7). 전자 발급분은 면제 | 2차 자료끼리 일치 |
| 전자기부금영수증 의무 | 2025년 기부분부터, 직전연도 발급 합계 **3억 원 이상** 단체는 다음 해 **1월 10일**까지 홈택스로 발급 | 정책브리핑·국세청 확인 |
| 주민등록번호 | 법령 근거가 있을 때만 처리 가능(개인정보보호법 제24조의2). 영수증 발급 근거 조문을 따름 | 해설 자료 기준 |

## 🇺🇸 미국 이민교회 — Contribution Statement (헌금 영수증)

### 앱에서 하는 일
1. **설정**에 교회 이름, **주소**(필수), **EIN**(선택), **회계 담당자 이름**을 입력합니다.
2. **교인** 화면에서 영수증 받을 분의 **주소**를 입력합니다. SSN 입력칸은 없습니다.
3. **영수증** 화면에서 **Tax Year**를 고르고 **발급·인쇄** 또는 **전체 발급·인쇄**를 누릅니다. PDF로 저장해 이메일로 보내도 됩니다.

### 앱이 자동으로 넣는 내용
- 교회 이름, 주소, EIN / 헌금자 이름(부부 공동 헌금이면 함께 표시)과 주소
- **헌금별** 날짜 · 항목 · 방법(Cash/Check/Zelle 등) · 금액, 연간 합계
- IRS 기준 문구:
  > **No goods or services were provided in exchange for these contributions other than intangible religious benefits.**
  > 위 헌금에 대하여 무형의 종교적 혜택 외에 어떠한 재화나 용역도 제공되지 않았습니다.
- 발행일, 서명란, Statement No.(일련번호)

### 꼭 알아 둘 IRS 규정 (조사 확인 결과)
| 항목 | 내용 |
|---|---|
| **$250 기준** | **한 번에** $250 이상 헌금하면 헌금자는 교회의 서면 확인서가 있어야 공제받을 수 있습니다. 여러 번을 합산하지 않습니다(예: 매주 $25는 대상 아님). |
| **들어가야 할 것** | 교회 이름, 현금 헌금액, 현물이면 내용 설명(가액은 적지 않음), 재화·용역 제공 여부. 교회는 *intangible religious benefits* 문구로 대신할 수 있습니다. |
| **SSN** | IRS Pub. 1771: 헌금자의 SSN이나 납세자번호를 넣을 필요가 없습니다. 보아스는 넣지 않습니다. |
| **연간 1장** | 연간 요약서 하나로 여러 헌금을 함께 증명할 수 있습니다. 날짜·금액을 함께 적는 것이 권장되며, 보아스는 헌금별로 표시합니다. |
| **시기** | 헌금자가 세금 신고하기 전(신고일과 신고기한 중 빠른 날)까지 받아야 합니다. 교회가 **1월 31일까지** 보내는 것은 **관행**이고 법정 기한은 아닙니다. |
| **소액 현금 기록** | 금액과 관계없이 현금 헌금은 은행 기록이나 교회의 서면 기록(이름·날짜·금액)이 있어야 합니다. 보아스 statement가 이 역할을 합니다. |
| **대가성 헌금($75 초과)** | 식사·물품 등 대가를 받는 헌금이 $75를 넘으면, 공제는 대가를 넘는 부분만 된다는 점과 대가의 공정가치 추정치를 서면으로 알려야 합니다. 보아스 기본 문구는 대가 없는 헌금용이므로 **바자회·식사권 판매 같은 대가성 수입은 '헌금' 항목이 아닌 잡수입 등으로 입력**하세요. |
| **2026년부터** | 항목별 공제를 하지 않는 사람도 현금 기부를 최대 $1,000(부부 $2,000)까지 공제받을 수 있습니다(IRS Tax Topic 506). 영수증이 더 중요해집니다. |

## 공통 — 영수증 발급 전 점검표
- [ ] 연말까지의 헌금 입력을 마치고 **12월 마감**
- [ ] 이름 오타·동명이인 확인(교인번호 기준으로 합산되는지)
- [ ] 무명 헌금은 영수증 대상에서 빠지는 것이 정상
- [ ] 부부 공동 헌금은 성명2에 배우자 이름 확인
- [ ] (한국) 영수증 대상자의 주민등록번호·주소 입력
- [ ] (미국) 대상자 주소 입력, 교회 주소·EIN 입력
- [ ] 발급 후 **발급명세 대장(엑셀)** 저장 → 백업
