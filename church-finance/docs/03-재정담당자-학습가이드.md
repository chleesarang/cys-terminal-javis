# 🎓 목회자·재정담당자 학습 가이드

> 이 가이드는 **앱 사용법보다 한 단계 위**, 즉 *교회 재정을 투명하고 안전하게 운영하는 원리*를 다룹니다. 새로 맡은 재정 담당자는 4주 학습 계획(맨 아래)을 따라가면 됩니다. 목회자는 1~3장과 7장만 읽어도 충분합니다.

---

## 1. 교회 재정 5대 원칙

| 원칙 | 뜻 | 보아스에서는 |
|---|---|---|
| **① 분리** | 세는 사람, 기록하는 사람, 지출을 결재하는 사람이 달라야 합니다. | 계수자 2명 기록, 지출결의서 결재란 |
| **② 증빙** | 모든 지출에는 영수증이 있어야 하고, 없으면 사유를 남깁니다. | 사진·영상·PDF 첨부, 증빙 없음 사유 필수 |
| **③ 기록 보존** | 고친 흔적까지 남깁니다. 지우지 않습니다. | 해시 체인 감사로그, 삭제도 기록으로 남음 |
| **④ 정기 보고** | 매월(또는 분기) 제직회, 연 1회 공동의회에 보고합니다. | 주·월·분기·연 보고서 자동 생성 |
| **⑤ 독립 감사** | 재정과 관계없는 감사가 확인합니다. | 감사 자료 ZIP, 무결성 확인, 자동 감사 점검 |

> 💬 **목회자께**: 재정 사고는 대개 *나쁜 사람*보다 *허술한 절차* 때문에 일어납니다. 원칙 ①과 ③만 지켜져도 대부분의 오해와 사고를 막을 수 있습니다. 그리고 이 원칙은 담당자를 의심하려는 것이 아니라 **담당자를 보호**하기 위한 것입니다.

## 2. 역할과 책임

| 역할 | 하는 일 | 앱에서 |
|---|---|---|
| **담임목사** | 예산 방향 제시, 결산 보고 확인, 복구코드 1부 보관 | 보고서 열람, 결의서 결재 |
| **재정부장** | 예산 편성 주관, 지출 결재, 월 마감 확인, 복구코드 1부 보관 | 예산, 마감, 백업 확인 |
| **회계(재정 담당)** | 헌금·지출 입력, 증빙 관리, 보고서 작성 | 헌금·지출·장부·보고서 |
| **계수위원(2명 이상)** | 주일 헌금을 함께 세고 계수표에 서명 | 현금 계수표 |
| **감사** | 분기·연간 감사, 통장 대조, 증빙 확인 | 감사 자료 ZIP, 감사로그 |

## 3. 꼭 알아야 할 용어

- **관·항·목**: 예산 항목의 큰 분류, 중간 분류, 세부 분류입니다. 예: 교육비(관) › 교회학교(항). 보아스 기본값은 관·항 2단계이고, 교회 예산서에 맞게 고칠 수 있습니다.
- **일반회계 / 특별회계**: 건축헌금처럼 목적이 정해진 돈(지정헌금)은 **특별회계**로 따로 관리합니다. 일반 운영비로 쓰려면 제직회·공동의회 결의가 필요합니다.
- **전기이월 / 차기이월**: 지난 기간에서 넘어온 잔액과 다음 기간으로 넘기는 잔액입니다. *차기이월 = 전기이월 + 수입 − 지출*
- **집행률**: 연 예산 대비 지금까지 쓴(들어온) 비율입니다. 예산이 1년 단위이므로 6월 말에는 50% 안팎이 정상입니다.
- **추경(추가경정예산)**: 회계연도 중에 예산을 고치는 것입니다. 앱에서는 '확정 해제'를 누르고 사유를 남긴 뒤 수정합니다.
- **마감**: 보고가 끝난 기간을 잠그는 것입니다. 이후 수정에는 사유가 기록됩니다.
- **지출결의서**: 지출을 결재받는 문서입니다. 금액, 항목, 내용, 증빙, 결재란이 들어갑니다.
- **증빙**: 영수증, 카드 전표, 이체 확인증, 세금계산서 등 지출을 증명하는 자료입니다.

## 5. 점검표

### 매주 (주일)
- [ ] 계수위원 2명이 함께 계수하고 계수표에 서명
- [ ] 헌금 입력 → 미리보기 확인 → 저장
- [ ] 현금 계수표 저장 → **장부와 일치** 확인
- [ ] 헌금 집계표 2부 인쇄(계수자용, 회계용)
- [ ] 현금은 당일 또는 다음 날 통장에 입금

### 매월
- [ ] 영수증 누락 지출 0건(보고서 › 자동 감사 점검)
- [ ] 통장 잔액 대조(🏦) → 차이 0원
- [ ] 월간 보고서 인쇄 → 제직회 보고
- [ ] 보고가 끝나면 **기간 마감**
- [ ] **백업 파일** 만들어 보관

### 분기
- [ ] 분기 보고서와 예산 대비 집행률 검토(초과 항목 확인)
- [ ] 감사에게 **감사 자료 ZIP** 전달
- [ ] 감사로그 **무결성 검사**(설정 › 감사로그) → 정상

### 연간
- [ ] 연간 결산 보고서 → 감사 → 공동의회
- [ ] 기부금영수증 / Contribution Statement 일괄 발급
- [ ] 발급명세 대장(엑셀) 저장(한국: 5년 보관)
- [ ] 다음 연도 예산 확정, 전기이월 확인

## 6. 보고서 읽는 법 (제직회용)

1. **요약표**: 회계별로 *전기이월 + 수입 − 지출 = 차기이월*이 맞는지 봅니다.
2. **수입**: 헌금 종류별로 이번 기간 금액과 연 누계를 봅니다. 작년 같은 기간과 비교하면 흐름이 보입니다.
3. **지출**: **집행률**이 기간 비율보다 크게 높은 항목을 살핍니다. 예: 3월인데 80%라면 확인이 필요합니다.
4. **주일별 헌금**: 특정 주일에 크게 튀는 값이 있으면 입력 실수가 없었는지 확인합니다.
5. **감사 점검 사항**: 항목마다 '확인' 버튼으로 원본을 열어 처리합니다.

## 7. 개인정보 원칙 (목회자 필독)

- 헌금 내역과 교인 정보는 **신앙을 드러내는 정보**이므로 민감정보로 다루는 것이 안전합니다.
- **최소 수집**: 연락처는 필요할 때만 받고, 주민등록번호(한국)는 영수증을 원하는 분만 받습니다. 미국은 SSN을 받지 않습니다.
- **동의**: 교인 명부와 헌금 기록 관리에 대한 동의를 받아 두세요(개인정보 동의와 민감정보 동의는 따로 받는 것이 권장됩니다).
- **외부 제공 금지**: 노회·교단 등에 명단을 보낼 때는 동의 범위 안에서만 보냅니다. 보아스는 인터넷으로 아무것도 보내지 않습니다.
- **AI에 보낼 때**: 이름이 보이는 헌금 명단 사진보다 **교인번호**가 보이는 자료를 보내고, 영수증 위주로 보냅니다.

## 8. 흔한 실수와 예방

| 실수 | 예방 |
|---|---|
| 계수와 입력을 한 사람이 혼자 함 | 계수자 2명 기록을 습관화 |
| 건축헌금을 일반 지출에 섞어 씀 | 특별회계로 분리. 전용하려면 결의 |
| 영수증을 나중에 모으다 잃어버림 | 쓰는 즉시 📷 촬영·저장 |
| 비밀번호를 한 사람만 알고 있다가 그 사람이 떠남 | 복구코드 2부를 담임목사·재정부장이 보관 |
| 휴대폰을 바꾸면서 자료가 사라짐 | 월 1회 이상 백업, 바꾸기 전 백업 |
| 지난달 기록을 몰래 고친다는 오해 | 마감 + 수정 사유 기록 + 감사로그 |

| 3주 | 이 가이드 4~6장, 사용설명서 5~7장 | 월간 보고서 인쇄, 마감, 백업·복원 연습 |
| 4주 | [교회 내부 운영 규칙](05-교회-내부-운영규칙.md), [AI 가이드](06-AI-활용-가이드.md) | 실제 장부로 전환(전기이월 입력), 선임자와 함께 첫 주일 처리 |

### 확인 문제 (정답은 맨 아래)
1. 계수는 최소 몇 명이 함께 해야 할까요?
2. 영수증이 없는 지출을 저장하려면 무엇이 필요할까요?
3. 건축헌금은 어느 회계로 관리할까요?
4. 마감된 기간을 고치면 무엇이 남나요?
5. 비밀번호를 잊었을 때 장부를 여는 방법은?
6. 백업 파일은 클라우드에 올려도 안전할까요? 그 이유는?
7. 미국 이민교회에서 $250 이상 단일 헌금자에게 꼭 필요한 문서는?
8. 한국에서 기부금영수증 발급명세는 몇 년 보관하나요?
9. 6월에 연간 집행률 90%인 항목이 있다면?
10. AI에 헌금 명단 사진을 보낼 때 권장하는 방법은?

> **정답** — 1) 2명 2) 증빙 없음 사유 3) 특별회계(건축회계) 4) 사유와 변경 전후 내용이 감사로그에 남음 5) 복구코드 6) 안전. 암호화되어 비밀번호·복구코드 없이는 열 수 없음 7) 서면 확인서(Contribution Statement) 8) 5년 9) 원인 확인, 필요하면 추경 10) 이름 대신 교인번호가 보이게, 최소한만
