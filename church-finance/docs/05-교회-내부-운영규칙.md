# 🏛 교회 내부 운영 규칙 (예시안)

> 아래는 보아스를 쓰는 교회가 **제직회(또는 당회) 결의로 채택**할 수 있는 재정 운영 세칙 예시입니다. 교회 정관·교단 헌법이 우선하며, 교회 사정에 맞게 고쳐 쓰세요. ○○ 부분을 채우면 됩니다.

---

## ○○교회 재정 운영 세칙 (예시)

**제1조(목적)** 이 세칙은 ○○교회 재정을 투명하고 안전하게 관리하기 위해 헌금의 계수·기록, 지출, 보고, 감사, 재정 앱(보아스) 사용에 필요한 사항을 정한다.

**제2조(회계연도)** 회계연도는 매년 ○월 1일부터 다음 해 ○월 말일까지로 한다.

**제3조(회계 구분)** 재정은 일반회계와 특별회계(건축회계 등)로 구분한다. 목적이 정해진 헌금은 해당 특별회계로 관리하며, 다른 용도로 쓰려면 ○○(제직회/공동의회) 결의를 거친다.

**제4조(헌금 계수)**
1. 헌금은 계수위원 **2명 이상**이 함께 계수한다.
2. 계수 결과는 앱의 **현금 계수표**에 기록하고 계수자 이름을 남긴다.
3. **헌금 집계표**는 2부 인쇄해 계수자 대표와 회계가 각각 서명·보관한다.
4. 현금은 계수한 날 또는 다음 은행 영업일에 교회 통장에 입금한다.

**제5조(기록)**
1. 헌금과 지출은 회계가 **일주일 이내**에 앱에 입력한다.
2. 이미 저장한 기록은 지우지 않으며, 고치거나 삭제할 때는 **사유**를 남긴다.

**제6조(지출)**
1. 지출은 예산 범위에서 한다. 1건에 ○○원 이상인 지출은 재정부장, ○○원 이상인 지출은 담임목사의 결재를 받는다.
2. 모든 지출은 영수증 등 **증빙을 앱에 사진으로 첨부**한다. 증빙을 받을 수 없으면 사유를 기록한다.
3. 현금 지출은 가능한 한 줄이고, 계좌이체나 교회 카드를 우선 사용한다.

**제7조(보고)**
1. 회계는 매월 **월간 재정 보고서**를 작성해 다음 달 첫 제직회에 보고한다.
2. 연간 결산 보고서는 감사를 거쳐 공동의회에 보고한다.
3. 보고가 끝난 기간은 **기간 마감**으로 잠근다.

**제8조(감사)**
1. 감사는 재정 업무를 맡지 않은 사람 ○명으로 한다.
2. 감사는 분기마다 앱의 **감사 자료 묶음(ZIP)** 과 통장 잔액 대조 결과를 확인하고 감사 보고서를 낸다.

**제9조(재정 앱 보안)**
1. 앱 비밀번호는 회계와 재정부장만 안다. 비밀번호는 다른 사람과 나누지 않는다.
2. **복구코드**는 종이에 적어 2부를 만들고, 담임목사와 재정부장이 각각 봉투에 넣어 따로 보관한다.
3. 앱을 설치한 기기는 화면 잠금을 설정한다. 공용 PC에는 설치하지 않거나, 쓴 뒤 반드시 잠근다.
4. 회계는 **매월 마감 후 백업 파일**을 만들어 교회 공용 클라우드(구글드라이브 등)에 보관한다.

**제10조(개인정보)**
1. 교인 정보와 헌금 기록은 재정 목적으로만 쓰며, 동의 없이 외부에 제공하지 않는다.
2. (한국) 주민등록번호는 기부금영수증을 원하는 교인에게서만 받는다. (미국) SSN은 받지 않는다.
3. AI 도구를 쓸 때는 이름 대신 교인번호를 쓰는 등 개인정보를 최소화한다.

**제11조(인수인계)** 재정 담당자가 바뀌면 [인수인계 점검표](#인수인계-점검표)에 따라 인수인계하고 재정부장이 확인한다.

**부칙** 이 세칙은 ○○년 ○월 ○일 ○○ 결의로 시행한다.

## 인수인계 점검표
- [ ] 마지막 월까지 입력 완료 · 보고 · **마감**
- [ ] 최신 **백업 파일** 생성, 새 담당자 기기에서 **불러오기** 성공 확인
- [ ] 새 담당자가 **비밀번호 변경**(설정 › 비밀번호 변경). 이전 담당자 기기의 앱은 **설정 › 모든 데이터 삭제**
- [ ] 복구코드 보관 상태 확인(담임목사·재정부장)
- [ ] 통장·카드·인감 등 실물 인계(앱 밖)
- [ ] 미처리 영수증, 미입력 헌금 목록 인계
- [ ] 감사로그 **무결성 검사** 정상 확인 후 재정부장 서명

## 사고 대응
| 상황 | 바로 할 일 |
|---|---|
| 휴대폰·PC 분실 | 앱 자료는 암호화되어 있어 비밀번호 없이는 열 수 없습니다. 다른 기기에 최신 백업을 **불러오고**, **비밀번호를 변경**합니다. 기기 화면 잠금도 원격으로 잠그세요. |
| 비밀번호 분실 | 잠금 화면 › **복구코드로 열기** → 새 비밀번호 설정 |
| 복구코드와 비밀번호 모두 분실 | 앱 자료를 열 수 없습니다. **비밀번호를 아는 사람이 있을 때** 백업을 만들어 두는 것이 유일한 예방책입니다. |
| 백업을 오래 안 함 + 기기 고장 | 마지막 백업 이후 기록은 종이 계수표·영수증·통장 내역으로 다시 입력합니다. |
| 계수 금액과 장부 불일치 | 보고서 › 자동 감사 점검에서 해당 날짜를 열어 입력 오류를 찾고, 고칠 때 사유를 남깁니다. |
| 재정 의혹 제기 | 감사 자료 ZIP과 감사로그 무결성 결과를 감사에게 제출합니다. 기록이 고쳐졌다면 변경 전후 내용이 모두 남아 있습니다. |
