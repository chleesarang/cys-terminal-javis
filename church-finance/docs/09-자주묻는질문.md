# ❓ 자주 묻는 질문 · 문제 해결

## 보안 · 자료
**Q. 우리 교회 자료는 어디에 저장되나요? 회사가 볼 수 있나요?**
교회가 쓰는 기기(휴대폰·PC) 안에만 **암호화**되어 저장됩니다. 서버가 없고 앱은 인터넷으로 아무것도 보내지 않으므로 회사도 볼 수 없습니다.

**Q. 휴대폰을 잃어버렸어요.**
앱 자료는 비밀번호 없이는 열 수 없습니다. 다른 기기에서 최신 백업을 불러오고 **비밀번호를 변경**하세요. 휴대폰 자체의 원격 잠금(삼성 '내 디바이스 찾기', 애플 '나의 찾기')도 함께 하세요.

**Q. 비밀번호를 잊었어요.**
잠금 화면 아래 **복구코드로 열기**를 누르고 복구코드를 입력하면 새 비밀번호를 정할 수 있습니다.

**Q. 비밀번호도 복구코드도 없어요.**
암호화 특성상 **누구도 열 수 없습니다**(회사도 불가). 그래서 처음 설정할 때 복구코드 2부를 따로 보관하도록 안내합니다.

**Q. 브라우저 기록을 지우면 자료가 사라지나요?**
브라우저의 '사이트 데이터 삭제'를 하면 이 기기의 자료가 지워질 수 있습니다. **백업 파일**이 있으면 '백업 파일로 시작'으로 되살릴 수 있으니 매월 백업하세요.

## 기기 · 설치
**Q. PC와 휴대폰을 같이 쓰고 싶어요.**
한쪽에서 **백업 파일 만들기** → 다른 쪽에서 **백업 불러오기(합치기)** 를 합니다. 두 기기의 기록이 합쳐집니다. 실시간 자동 동기화는 아직 없습니다(서버를 두지 않기 위한 선택).

**Q. 여러 사람이 동시에 입력해도 되나요?**
각자 입력한 뒤 백업 파일로 합칠 수 있습니다. 같은 거래를 두 사람이 동시에 고치면 **나중에 고친 내용**이 남고, 변경 기록은 모두 감사로그에 남습니다. 혼선을 막으려면 입력 담당을 정해 두세요.

**Q. 인터넷이 없어도 되나요?**
처음 한 번 연 뒤에는 인터넷 없이 됩니다. 업데이트는 인터넷에 연결되었을 때 받습니다.

**Q. 아이폰에서 🎤 말하기 버튼이 안 보여요.**
아이폰 홈 화면 앱에서는 브라우저 음성 인식이 동작하지 않아 숨겼습니다. 대신 **키보드의 마이크(받아쓰기)** 를 쓰세요. 그쪽이 더 정확하고 개인정보에도 더 안전합니다.

## 입력
**Q. 금액을 '10만'으로 써도 되나요?**
네. `10만`, `10만5천원`, `삼십이만 사천`, `100,000` 모두 됩니다. 미국 모드에서는 `150`, `$150.50`, `100불`이 됩니다.

**Q. 미국 모드에서 '3'을 쓰면 3달러인가요, 3번 교인인가요?**
**줄에 숫자 하나만** 있거나 **줄 맨 앞 숫자**는 교인번호입니다. 3달러를 입력하려면 `무명 3` 또는 `$3`처럼 쓰세요.

**Q. 동명이인이 있어요.**
교인 명부의 **번호**로 입력하세요(`12` 또는 `#12`). 이름만 쓰면 동명이인일 때 연결하지 않고 이름만 기록합니다.

**Q. 지출 항목이 자꾸 틀리게 골라져요.**
한 번 바로잡아 저장하면 다음부터 같은 메모는 그 항목으로 갑니다. **설정 › 예산 항목**에서 키워드를 추가해도 됩니다.

**Q. 지난달 기록을 고쳐야 해요(마감됨).**
장부에서 해당 건을 열어 고치고 **사유**를 입력하면 됩니다. 변경 전후 내용이 감사로그에 남습니다.

## 보고 · 영수증
**Q. 잔액이 마이너스로 나와요.**
처음 쓰는 해라면 **예산 › 전기 이월금**(앱 시작 시점의 통장 잔액)을 입력하세요.

**Q. 계수표와 장부가 안 맞아요.**
결제 방법이 '현금'인 헌금만 계수와 비교합니다. 계좌·수표로 들어온 헌금의 방법이 '현금'으로 되어 있지 않은지 확인하세요.

**Q. 기부금영수증 서식이 바뀌었다고 해요.**
배포사가 앱을 업데이트합니다. 급할 때는 [영수증 가이드](04-영수증-가이드-한국-미국.md)의 공식 링크에서 최신 서식을 확인하세요.

**Q. 한국/미국 모드를 잘못 골랐어요.**
**거래를 입력하기 전**이면 설정에서 바꿀 수 있습니다. 이미 입력했다면 금액 단위가 달라지므로, 백업 후 **모든 데이터 삭제** → 다시 설정해야 합니다.

**Q. 엑셀로 열고 싶어요.**
보고서 › **📗 엑셀**을 누르면 거래내역·항목별·회계별·주일별 시트가 들어 있는 엑셀 파일이 만들어집니다.

## 비용
