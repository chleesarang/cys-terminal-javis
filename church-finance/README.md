# 청지기 장부 — 교회 재정 · 헌금 · 결산 자동화 (무료)

서버·회원가입·구독 없이, **교회 PC와 휴대폰 브라우저에 설치해서 쓰는** 교회 재정 앱입니다.
모든 자료는 **기기 안에 암호화**되어 저장되고, 배포하는 회사도 교회 자료를 볼 수 없습니다.

- 매주 1~2회, 10분 입력 → 주간·월간·분기·연간 결산과 제직회 보고서가 자동으로 만들어집니다.
- 입력 방법: 타이핑, 음성(휴대폰 키보드 마이크), 녹음을 받아쓴 글 붙여넣기, 영수증 사진, 무료 AI 결과 붙여넣기.
- 합계·결산·보고서 계산은 앱이 직접 합니다. AI 토큰은 0입니다. AI는 사진처럼 형식이 정해지지 않은 입력에만 선택적으로 씁니다.

## 1. 참고 영상('요셉의 곳간') 대비 무엇이 나은가

참고 영상(약 2분)을 장면별로 분석해 비교했습니다. 영상에서 확인된 장점은 모두 넣었고, 확인된 약점은 보완했습니다. 표의 '—'는 '영상에서 확인되지 않음'이라는 뜻이며, 해당 기능이 없다는 단정이 아닙니다.

| 기능 | 요셉의 곳간(영상에서 확인된 범위) | 청지기 장부 |
|---|---|---|
| 교인 번호로 입력, 이름 오타 방지 | ○ | ○ (`12 십일조 10만`, `#12`, `김철수(12)` 모두 인식) |
| 주일헌금 주정 금액 자동 입력 | ○ | ○ (번호만 쓰면 주정 금액이 들어감) |
| 부부 공동 헌금(성명2) | ○ | ○ (`김철수 이영희 부부 감사 10만`) |
| 교인 명부 엑셀 붙여넣기·CSV 가져오기 | ○ | ○ (제목줄 자동 인식, 열 맞추기) |
| 기부금영수증 자동 발급, 일련번호 중복 없음 | ○ | ○ + 재발급 시 이전 번호 무효 처리, 발급명세 대장(엑셀) |
| 예산 편성(작년 복사, 결산 기반, 비율 조정, 확정) | ○ | ○ |
| 결산·통계·주간 보고서, 인쇄·PDF | ○ (HWP·PDF) | ○ (PDF·엑셀·CSV. HWP는 로드맵) |
| 서버·구독 없음 | ○ | ○ |
| **휴대폰 사용** | — (영상에는 Windows PC 프로그램만 나옴) | **○** (PC·안드로이드·아이폰, 홈 화면에 설치) |
| **음성 입력** | — | **○** (키보드 마이크, 녹음 받아쓴 글 붙여넣기) |
| **영수증 사진·영상 증빙** | — | **○** (촬영 → 암호화 보관 → 지출결의서·감사 ZIP에 자동 포함) |
| **메모만 쓰면 예산 항목 자동 분류** | — | **○** (키워드 + 그 교회의 과거 입력을 학습. AI 없이 동작) |
| **AI 사진 인식(무료)** | — | **○** (무료 Gemini·Claude·ChatGPT에 지침을 한 번 저장한 뒤 사진과 "영수증" 한 단어만 보냄) |
| **주민등록번호 보호** | 명부에 주민번호 열이 있고, 기록은 '프로그램 없이도 열리는 일반 엑셀 파일'에 저장 | **○** AES-256 암호화, 화면 가림, 감사로그에도 남기지 않음 |
| **변경 이력·위변조 탐지** | — | **○** 해시 체인 감사로그. 한 글자만 바뀌어도 탐지 |
| **기간 마감** | — | **○** 마감 이후 수정·삭제는 사유를 입력해야 함 |
| **전월 이월 자동** | 전월을 먼저 저장해야 함("전월 이월금 알 수 없음" 경고 장면) | **○** 전년·전월 잔액 자동 이월 |
| **특별회계(건축 등) 분리** | 잔액 표시만 | **○** 회계별 이월, 수입, 지출, 잔액 |
| **현금 계수표(2인)·장부 대조** | — | **○** 권종별 매수, 계수자 2명, 차이 자동 경고, 집계표 2부 인쇄 |
| **통장 잔액 대조** | — | **○** 통장 잔액과 장부 잔액의 차이를 보고서에 표시 |
| **자동 감사 점검** | — | **○** 증빙 누락, 중복 의심, 고액 현금, 미분류, 계수 불일치, 마감 후 변경 |
| **감사 자료 묶음** | — | **○** 보고서·지출결의서·엑셀·증빙 원본·감사로그·SHA-256 무결성 목록을 ZIP 하나로 |
| **기기 간 이동·백업** | 장부 파일 복사 | **○** 암호화 백업 파일. 다른 기기에서 불러오면 자동으로 합쳐짐 |
| **담당자 교체·비밀번호 분실** | — | **○** 복구코드(담임목사·재정부장이 보관) |

## 2. 교회용 빠른 사용법

### 처음 한 번 (10분)
1. 배포사가 안내한 주소를 **크롬(안드로이드·PC)** 이나 **사파리(아이폰)** 로 엽니다.
   - 아이폰: 공유 버튼 → **홈 화면에 추가**
   - 안드로이드·PC 크롬: 메뉴 → **앱 설치**(또는 홈 화면에 추가)
2. 교회 이름, 회계연도 시작 월, 비밀번호를 입력합니다.
3. 화면에 나오는 **복구코드를 종이에 적어** 담임목사와 재정부장이 따로 보관합니다. 비밀번호를 잊었을 때 장부를 열 방법은 이 코드뿐입니다.
4. **설정**에서 고유번호, 소재지, 대표자를 입력합니다. 기부금영수증에 이 정보가 인쇄됩니다.
5. **교인** 메뉴에서 엑셀 명부를 복사해 붙여넣습니다(번호, 이름, 주정, 연락처).
6. **예산** 메뉴에서 올해 예산과 **전기 이월금**(현재 통장 잔액)을 입력합니다.
7. 필요하면 **설정 › 예산 항목**을 교회 예산서와 똑같이 맞춥니다(관·항, 별칭, 키워드).

### 매주 (주일 오후 5~10분)
- **헌금**: 날짜 '이번 주일'을 확인하고 한 줄에 한 건씩 입력합니다. 음성으로 입력할 때는 휴대폰 키보드의 🎤를 누르고 말합니다. `미리보기`로 확인한 뒤 `저장`합니다.
  ```
  12 십일조 10만
  3                ← 번호만 쓰면 주정헌금 자동
  김철수 이영희 부부 감사 5만원
  무명 32만 4천원
  선교 박민수 삼만원 계좌이체
  ```
- **현금 계수표**: 권종별 매수와 계수자 2명을 적고 `계수 저장`합니다. 장부와 맞지 않으면 바로 경고가 뜹니다. `헌금 집계표 2부 인쇄`로 출력합니다.
- **지출**: 금액과 간단한 메모(예: `교회학교 간식`)를 입력하면 예산 항목이 자동으로 골라집니다. 📷로 영수증을 찍고 `저장`합니다.
- 녹음해 둔 파일은 갤럭시 '음성 녹음 → 텍스트 변환'이나 아이폰 '음성 메모 → 전사'로 글로 바꿔 헌금 입력칸에 붙여넣습니다. AI 비용이 들지 않습니다.

### 매월·분기·연말
- **보고서**에서 기간(주간·월간·분기·반기·연간·기간 지정)을 고르고 `인쇄·PDF 저장`을 누르면 제직회 보고서가 나옵니다.
- 제직회 보고가 끝나면 **설정 › 기간 마감**으로 그 기간을 잠급니다.
- 감사 때는 **감사 자료 묶음(ZIP)** 하나로 보고서, 지출결의서, 엑셀, 영수증 원본, 감사로그, 무결성 목록을 함께 전달합니다.
- 1월에는 **영수증** 메뉴에서 연도를 고르고 `전체 발급·인쇄`를 누릅니다. 발급명세 대장 엑셀은 5년간 보관합니다.
- **2주에 한 번 백업**(설정 › 백업 파일 만들기)해서 구글드라이브나 카카오톡 '나에게 보내기'에 보관합니다. 백업 파일은 암호화되어 있어 비밀번호나 복구코드 없이는 열 수 없습니다.

### PC와 휴대폰을 함께 쓰기
한쪽 기기에서 백업 파일을 만들고, 다른 기기의 **설정 › 백업 불러오기(합치기)** 로 불러옵니다. 거래별로 가장 최근에 수정한 내용이 남고, 새 기록은 모두 합쳐집니다.

## 3. AI 활용 (무료 기본, 필요할 때만 월 $20)

앱은 AI API를 직접 호출하지 않습니다. 교회가 이미 쓰는 **무료 AI 앱**과 복사·붙여넣기로 연결합니다(API 키나 과금 없음).

1. **AI 도우미 › 지침 복사**를 누르고, 다음 중 한 곳에 **한 번만** 저장합니다.
   - **Gemini (무료 추천)**: Gem 만들기. 녹음 파일(m4a)도 무료로 받습니다.
   - **Claude (무료)**: 프로젝트 지침에 저장합니다.
   - **ChatGPT (무료)**: 프로젝트 지침에 저장합니다. 무료 플랜은 사진 업로드 횟수가 적습니다.
2. 이후에는 영수증 사진과 함께 **"영수증"** 한 단어만 보냅니다(헌금 명단 사진은 "헌금").
3. AI 답변을 그대로 복사해 **AI 도우미 › 붙여넣기**에 넣습니다. 앱이 합계를 검산하고, 항목 코드가 비어 있으면 로컬 규칙으로 분류해 미리보기를 보여 줍니다.

AI 답변 형식은 파이프(`|`)로 구분한 한 줄입니다. 같은 내용을 JSON으로 받을 때보다 토큰이 1.6~2.6배 적습니다.
```
I|20261108|102|#12|100000        헌금: 날짜|항목코드|이름 또는 #번호|금액
O|20261107|262|23000|이마트 다과   지출: 날짜|항목코드|금액|내용
T|123000                          검산용 합계
```
- **월 $20 플랜(Claude Pro, ChatGPT Plus 등)** 은 사진을 많이 처리하는 큰 교회에만 필요합니다. 구독에는 API 사용권이 포함되지 않지만, 이 앱은 API를 쓰지 않으므로 구독만으로 충분합니다.
- **개인정보**: AI에는 이름 대신 **교인번호**가 보이게 찍거나, 이름이 없는 영수증 위주로 보내기를 권합니다. 장부와 명부는 앱 밖으로 나가지 않습니다.

## 4. 보안 설계

| 위협 | 대책 |
|---|---|
| 기기 분실·도난 | 장부, 명부, 증빙 전체를 AES-256-GCM으로 암호화합니다. 열쇠는 PBKDF2-SHA256(60만 회)로 비밀번호에서 만들고, 일정 시간 쓰지 않으면 자동으로 잠깁니다. |
| 비밀번호 분실·담당자 교체 | 무작위 데이터 키를 비밀번호와 복구코드로 각각 이중 래핑합니다. 비밀번호를 바꿀 때 데이터를 다시 암호화할 필요가 없습니다. |
| 서버 해킹·유출 | 서버가 없습니다. CSP `connect-src 'self'` 설정으로 외부 전송 경로 자체를 막았습니다(E2E 테스트에서 외부 요청 0건 확인). |
| 장부 조작 | 모든 변경을 해시 체인 감사로그에 기록하고, 마감한 기간을 수정할 때는 사유를 받습니다. 감사 ZIP에는 파일별 SHA-256 값이 들어갑니다. |
| 주민등록번호 | 선택 입력이며 암호화해 저장합니다. 화면과 명부 엑셀에서는 가리고, 감사로그에는 값을 남기지 않습니다. 영수증 인쇄에만 사용합니다. |
| 화면 공격(XSS) | 모든 사용자 입력을 자동 이스케이프하고, 스크립트는 `script-src 'self'`로 제한합니다. |
| 엑셀 수식 주입 | CSV에서 `= + - @`로 시작하는 문자열 앞에 `'`를 붙여 수식으로 실행되지 않게 합니다. |

**배포사 책임**: 앱 코드는 배포 주소에서 내려받습니다. 배포 저장소에는 2단계 인증과 보호 브랜치를 꼭 쓰세요. 보안 요구가 높은 교회는 이 폴더를 내려받아 직접 호스팅해도 됩니다.

## 5. 배포하기 (배포사용)

정적 파일뿐이라 무료 호스팅으로 충분합니다. 브라우저 보안 정책 때문에 반드시 **https**로 제공해야 하고, `file://`로 직접 열면 동작하지 않습니다.

- **GitHub Pages (무료)**: 이 `church-finance/` 폴더 내용을 별도 공개 저장소 루트에 올리고 Settings › Pages를 켭니다. 그 주소를 교회에 안내하면 됩니다.
- Cloudflare Pages, Netlify 등 다른 정적 호스팅도 같은 방식으로 됩니다.
- **업데이트**: 파일을 고쳐 올리면 다음 접속 때 자동 반영됩니다(서비스워커가 네트워크를 우선 사용). 큰 변경 때는 `sw.js`의 `VERSION`을 올리세요.
- **후원 안내**: `config.js`의 `SUPPORT` 항목에 회사명, 안내 문구, 계좌, 링크를 넣으면 설정 화면에 표시됩니다. 비워 두면 표시되지 않습니다.

로컬에서 확인하는 방법:
```bash
cd church-finance && python3 -m http.server 8080
```
브라우저로 http://localhost:8080 을 엽니다. localhost는 https가 아니어도 동작합니다.
