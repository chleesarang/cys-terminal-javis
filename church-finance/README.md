# 보아스 V1.0 — 교회(기관) 재정부 앱 (무료)

서버, 회원가입, 구독이 필요 없습니다. **교회 PC와 휴대폰 브라우저에 설치해서 쓰는** 재정부 앱입니다.
모든 자료는 **기기 안에 암호화**되어 저장되므로, 배포하는 회사도 교회 자료를 볼 수 없습니다.

- 매주 1~2회, 10분 입력하면 주간·월간·분기·연간 결산과 제직회 보고서가 자동으로 만들어집니다.
- 입력 방법: 교인번호, 타이핑, 말(휴대폰 키보드 마이크), 녹음을 글로 바꿔 붙여넣기, 영수증 사진·영상, 무료 AI 결과 붙여넣기
- 합계·결산·보고서는 앱이 직접 계산합니다(AI 토큰 0). AI는 사진처럼 형식이 정해지지 않은 입력에만 선택적으로 씁니다.
- **지역 모드**: 🇰🇷 한국 교회(원화, 국세청 기부금영수증) / 🇺🇸 미국 이민교회(달러·센트, IRS 기준 Contribution Statement)

📘 **사용설명서·교육 자료**: [docs/README.md](docs/README.md) (앱 안 **더보기 › 도움말**에서도 열림)

## 1. 무엇이 다른가 — 참고 영상의 기존 PC 프로그램과 비교

참고 영상(약 2분)에 나온 기존 교회 재정 PC 프로그램을 장면별로 분석했습니다. 영상에서 확인된 장점은 모두 넣었고, 확인된 약점은 보완했습니다. 표의 '—'는 '영상에서 확인되지 않음'이라는 뜻이며, 해당 기능이 없다는 단정이 아닙니다.

| 기능 | 기존 PC 프로그램(영상에서 확인된 범위) | 보아스 |
|---|---|---|
| 교인 번호로 입력, 이름 오타 방지 | ○ | ○ (`12 십일조 10만`, `#12`, `홍길동(12)`) |
| 주일헌금 주정 금액 자동 입력 | ○ | ○ (번호만 쓰면 자동) |
| 부부 공동 헌금 | ○ | ○ |
| 교인 명부 엑셀 붙여넣기·CSV | ○ | ○ (제목줄 자동 인식, 열 맞추기) |
| 기부금영수증, 일련번호 중복 없음 | ○ | ○ + 재발급 이력, 발급명세 대장 |
| 예산 편성(작년 복사·결산 기반·비율 조정·확정) | ○ | ○ |
| 결산·통계·주간 보고서, 인쇄 | ○ | ○ (PDF·엑셀·CSV) |
| 서버·구독 없음 | ○ | ○ |
| 휴대폰 사용 | — (영상에는 Windows PC 프로그램만 나옴) | **○** PC·안드로이드·아이폰 |
| 음성 입력 | — | **○** 키보드 마이크, 녹음 받아쓴 글 |
| 영수증 사진·영상 증빙 | — | **○** 암호화 보관, 지출결의서·감사 ZIP에 자동 포함 |
| 메모로 예산 항목 자동 분류 | — | **○** 키워드 + 교회별 학습(AI 없이) |
| AI 사진 인식(무료) | — | **○** 무료 Gemini·Claude·ChatGPT 연결 |
| 주민등록번호 보호 | 명부에 주민번호 열이 있고, '프로그램 없이도 열리는 일반 엑셀 파일'에 저장 | **○** AES-256 암호화, 화면 가림, 감사로그에 남기지 않음 |
| 미국 이민교회 영수증 | — | **○** IRS 기준 Contribution Statement(한영 병기) |
| 변경 이력·위변조 탐지 | — | **○** 해시 체인 감사로그 |
| 기간 마감 | — | **○** 마감 이후 수정은 사유 기록 |
| 이월 자동 | 전월을 먼저 저장해야 함('전월 이월금 알 수 없음' 경고 장면) | **○** 전월·전년 잔액 자동 이월 |
| 특별회계 분리 | 잔액 표시 | **○** 회계별 이월·수입·지출·잔액 |
| 현금 계수표(2인)·장부 대조 | — | **○** 권종별, 계수자 2명, 차이 경고, 집계표 2부 |
| 통장 잔액 대조·자동 감사 점검 | — | **○** |
| 감사 자료 묶음 | — | **○** 보고서·결의서·엑셀·증빙 원본·감사로그·SHA-256 목록을 ZIP 하나로 |
| 기기 간 이동·백업 | 장부 파일 복사 | **○** 암호화 백업, 불러오면 자동 병합 |
| 담당자 교체·비밀번호 분실 | — | **○** 복구코드 |

## 2. 지역 모드 (처음 설정에서 선택)

| | 🇰🇷 한국 교회 | 🇺🇸 미국 이민교회 |
|---|---|---|
| 금액 | 원, 정수(`10만`, `삼십이만 사천`) | 달러·센트(`150`, `$23.50`, `100불`) |
| 교인번호 | 1000 미만 정수, `#12`, `12번` | **줄 맨 앞 숫자** 또는 `#12` |
| 결제 방법 | 현금·계좌이체·수표·카드 | Cash·Zelle/온라인·Check·카드 |
| 현금 계수 권종 | 5만~10원 | $100~1¢ |
| 영수증 | 국세청 기부금영수증(별지 제45호의2서식 구조, 코드 41) | Contribution Statement: 헌금별 날짜·금액, *intangible religious benefits* 문구, SSN 없음 |
| 기부자 식별 | 주민등록번호(희망자만, 암호화) | 수집하지 않음 |
| 지출 자동 분류 | 한국어 키워드 | 한국어 + Costco·H마트·Home Depot·Shell 등 |

규정과 공식 링크는 [docs/04 영수증 가이드](docs/04-영수증-가이드-한국-미국.md)에 정리했습니다.

## 3. 배포 (회사용 요약)

정적 파일뿐이라 무료 호스팅으로 충분합니다. 브라우저 암호화 기능을 쓰려면 반드시 **https**여야 하고, `file://`로 직접 열면 동작하지 않습니다.

1. 이 폴더 내용을 회사의 공개 저장소에 올리고 GitHub Pages를 켭니다. 생긴 주소가 교회에 안내할 **앱 주소**입니다.
2. `config.js`의 `SUPPORT`에 회사명, 후원 안내, 문의처를 넣습니다.
3. 배포 저장소에는 2단계 인증과 보호 브랜치를 반드시 설정합니다.

자세한 절차, 온보딩, 교육 커리큘럼, 지원 원칙은 [docs/07 회사 보급·교육 가이드](docs/07-회사-보급-교육-가이드.md)에 있습니다.

로컬에서 확인하는 방법:
```bash
cd church-finance && python3 -m http.server 8080
```
브라우저로 http://localhost:8080 을 엽니다. localhost는 https가 아니어도 동작합니다.

## 4. 보안 설계

| 위협 | 대책 |
|---|---|
| 기기 분실·도난 | 장부·명부·증빙 전체를 AES-256-GCM으로 암호화합니다. 열쇠는 PBKDF2-SHA256(60만 회)로 만들고, 쓰지 않으면 자동으로 잠깁니다. |
| 비밀번호 분실·담당자 교체 | 무작위 데이터 키를 비밀번호와 복구코드로 각각 이중 래핑합니다. 비밀번호를 바꿀 때 데이터를 다시 암호화할 필요가 없습니다. |
| 서버 해킹·유출 | 서버가 없습니다. CSP `connect-src 'self'`로 외부 전송 경로를 차단했습니다(E2E 테스트에서 외부 요청 0건 확인). |
| 장부 조작 | 해시 체인 감사로그, 마감 후 수정 사유 기록, 감사 ZIP의 SHA-256 목록 |
| 주민등록번호 | 선택 입력, 암호화 저장, 화면·명부 엑셀에서 가림, 감사로그에 값 미기록. 미국 모드는 수집하지 않습니다. |
| XSS·엑셀 수식 주입 | 사용자 입력을 자동 이스케이프하고, CSV에서 `= + - @`로 시작하는 값을 무력화합니다. |

**배포사 책임**: 앱 코드는 배포 주소에서 내려받으므로, 배포 저장소 보안(2FA·보호 브랜치·리뷰)이 곧 교회 자료 보안입니다.

## 5. 개발 · 검증

```
church-finance/
  core/            순수 엔진 (브라우저·Node 공용, 외부 라이브러리 0)
    parse.js         한국어·달러 금액, 헌금·지출 문장 파서, 지출 자동 분류
    region.js        지역 모드(한국/미국): 통화·권종·영수증·용어
    ledger.js        장부·감사로그 해시 체인·마감·병합·예산·명부
    reports.js       결산·이월·회계별·예산 대비·자동 감사 점검·영수증 발급
    render.js        제직회 보고서·지출결의서·기부금영수증·Contribution Statement·헌금 집계표
    bridge.js        AI 지침·파이프 형식 답변 해석·검산
    crypto.js        WebCrypto 암호화 (DEK + 이중 래핑)
    zip.js           ZIP·XLSX·CSV 생성기
    md.js            도움말 문서 렌더러(안전한 마크다운)
    accounts.js      기본 계정과목(관·항)
  app.js · ui.js · views-*.js · store.js · sw.js   화면·저장소·오프라인
  docs/            사용설명서·학습 가이드·회사 교육 자료 (+ img/ 실제 화면)
  tests/core.test.mjs   단위 테스트
  tests/e2e.cjs         실제 브라우저 종단 테스트 (한국 + 미국 모드)
  tests/shots.cjs       매뉴얼 그림 자동 촬영
```
```bash
cd church-finance && npm test
```
```bash
cd church-finance && node tests/e2e.cjs
```
```bash
cd church-finance && node tests/shots.cjs
```
E2E 테스트와 그림 촬영에는 Playwright와 Chromium이 필요합니다.

### 확인된 사실과 미확인 사항 (정직 고지)
- 한국 기부금영수증은 별지 제45호의2서식의 **구조**를 따릅니다. 이 서식에 **2026.1.2 개정 표기**가 확인되었지만 개정 내용은 원문과 대조하지 못했습니다. 실제 발급 전에 국가법령정보센터 원문과 대조하세요.
- 미국 Contribution Statement 문구와 SSN 미기재는 IRS Pub. 1771 기준입니다. 주(州) 규정, 현물 헌금, 목회자 사례비 세무는 CPA와 확인하세요.
- 기본 계정과목은 공개된 교회 예결산서들을 종합한 것이며 교단 공식 표준이 아닙니다.
- 무료 AI 플랜의 한도와 기능은 각 회사 사정에 따라 수시로 바뀝니다(2026년 11월 조사 기준).
